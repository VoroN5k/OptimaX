# OptimaX

Утиліта для ігрових ПК на Windows 10/11, яка **вимірює**, що обмежує продуктивність у
грі, і **цифрами** показує, чи дала ефект кожна зміна. Розрахована на хороші ПК, де
класичні «твіки реєстру» майже нічого не дають.

Головний принцип — **жодного плацебо**: немає виміряного ефекту — немає рекомендації.
Якщо покращувати нічого, програма чесно це каже.

> **Статус: бета.** Можливі помилки. Відгуки — в [Issues](../../issues).

## Завантажити

[**Releases**](../../releases), два варіанти:
- `OptimaX-<версія>-win-x64-setup.exe` — інсталятор (Program Files, ярлик у «Пуск»);
- `OptimaX-<версія>-win-x64.zip` — портативна версія: розпакуй і запусти `OptimaX.exe`.

- Потрібен **WebView2** (на Windows 11 є вбудований, на Windows 10 майже завжди є; якщо
  ні — програма підкаже).
- Потрібні права адміністратора — Windows спитає при запуску.
- Exe не підписаний сертифікатом, тож SmartScreen може показати «Windows захистив ваш ПК»:
  «Докладніше» → «Однаково запустити».
- Дані програми (журнали, карантин, налаштування) — у `%ProgramData%\OptimaX\<SID>`
  (записувати туди можуть лише адміністратори, користувач — читати); вбудований PresentMon —
  у `%ProgramData%\OptimaX\bin`. Дані попередніх версій із `%LOCALAPPDATA%\OptimaX`
  переносяться автоматично при першому запуску.
- Встановлену інсталятором версію можна оновити з програми: «Налаштування → Оновлення»
  (інсталятор нової версії перевіряється за цифровим підписом). Портативну — вручну.

## Що вміє

- **Діагностика «Чому лагає?»** — запис гри через вбудований PresentMon і метрики системи;
  вердикт, що обмежує FPS: відеокарта, процесор, ліміт кадрів, VRAM, тротлінг, мікрофризи,
  фонові процеси, показ кадрів через композицію Windows. Кожен вердикт — з рівнем
  впевненості й доказами.
- **Оптимізація з відкатом** — кожна зміна системи записується в журнал і відкочується
  одним кліком; перед першою зміною створюється точка відновлення. A/B-тест (≥ 3 прогони
  «до» і «після») показує, чи був ефект; приріст у межах похибки = «ефекту немає».
- **Ігри** — режим гри й профілі для окремих ігор.
- **Очищення диска з вердиктами** — для кожного великого об'єкта: «Безпечно / З наслідками /
  Не чіпати / Невідомо», що це і що буде після видалення. Видаляється лише те, що збіглося
  з перевіреним правилом; невідоме не видаляється ніколи. Сухий прогін, карантин, журнал.
- **Залізо, Ноутбук, Мережа** — конфігурація системи, батарея й живлення, якість з'єднання
  (затримка, джитер, втрати — до роутера й за його межами).
- **Апскейл** — масштабування вікна гри (Lanczos, FSR 1, NIS тощо) із замірами доданої затримки.
- **Автозавантаження** — що стартує з Windows і скільки споживає зараз; вимкнення як у
  Диспетчері задач, з журналом і відкатом.
- **Резервні копії** — історія змін і відкат.

Програма не має телеметрії й не ходить у мережу без потреби (замір мережі — лише за кнопкою).

## Збірка з вихідного коду

Потрібні: Rust ≥ 1.95 (MSVC), Visual Studio Build Tools («Desktop development with C++»),
Node.js 22.

```powershell
cd ui
npm ci
npm run app:dev     # розробка (гаряче перезавантаження інтерфейсу)
npm run app:build   # портативний exe → target\release\optimax.exe
npm run app:bundle  # exe + інсталятор NSIS → target\release\bundle\nsis\
```

Перевірки перед комітом:

```powershell
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cd ui; npm run check; npm run check:i18n
```

Як випустити реліз — [docs/RELEASE.md](docs/RELEASE.md).

## Стек

Rust (Cargo workspace, крейти `crates/*`), Tauri 2, Svelte 5 + TypeScript.

перевіряється за SHA-256 перед кожним запуском).
